After having had the same questions from upstreams several times, last week I was finally carried away by a surge of JFDI energy to create a resource for them, of which here are the results:

- <https://wiki.ubuntu.com/Translations/Upstream>

This should provide some basic information about the relationship of Ubuntu Translations and upstreams, and it is aimed at both upstream maintainers and Ubuntu translators in an attempt to share knowledge and good practices for collaboration.

So, if you fall into any of those categories -or even if you don't-, I'd like to hear your comments and welcome your edits, especially if you see any info that's missing and you think might be useful to have there.

Thanks!

(I've been working on the main page, so you'll see that some of the sections for each particular upstream are just drafts for now, but stay tuned for more content.)
